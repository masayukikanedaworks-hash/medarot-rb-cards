# 通り芯照合ツール

基準図面と比較図面（他社作成図など）の PDF を読み込み、通り芯と芯々寸法の
食い違いを洗い出します。解析はブラウザだけで完結し、図面は外部に送信されません。
（任意機能の「AIで総ざらい」を押したときだけ、その図面PDFが外部APIに送信されます）

## 使う

`dist/zumen-check.html` をブラウザで開く。

1. 基準図面の PDF を読み込んで通り芯を判定
2. 比較図面で同じ操作
3. チェック項目を選んで照合

誤検出した通り芯はチェックを外して除外できます。

### 読み取れる図面の条件

次の5つを満たす図面を読み取れます。読み込むと自動で診断し、満たしていない条件が
あれば拾い出し結果の代わりに「どれが足りないか」と対処方法を表示します。

| 条件 | 満たさない例 |
| --- | --- |
| ベクターPDF（線のデータがある） | スキャン（画像）PDF |
| 文字が文字として入っている | CADのシングルストローク（SHX）フォントのまま出力した図面（※下記の「線で描かれた文字を教える」で読めます） |
| 通り芯の符号が円で囲まれている | 四角囲み・囲みなし |
| 符号が X○○ / Y○○ の書式 | A通り・1通り・い通りなど別の符号体系 |
| 寸法線が黒ドット＋直線＋数字 | 寸法線の端が斜線（／）や矢印 |

**同じCAD・同じ作図ルールで出力された図面なら、別の物件でもそのまま読めます。**
別の設計事務所の図面は、符号の囲み方や寸法線の端部の描き方が違うと読めないことが
あります。その場合でも診断でどこが違うかが分かりますし、「AIで総ざらい」は
図として読むのでこれらの条件に関係なく使えます。

### 線で描かれた文字を教える

CAD のシングルストローク（SHX）フォントのまま出力した図面は、数字も通り芯の符号も
「線の集まり」になり、PDF に文字データが残りません。この場合は診断の
**「線で描かれた文字を教えて読み取る」**から、形と文字の対応を一度だけ教えると、
そのまま寸法を読み取れます。

1. 図面に出てくる字形が一覧で並びます（出現回数の多い順）
2. 各マスの下に、その形が表す文字（0〜9 / . / X / Y）を入力します
3. 「この内容で読み取る」を押すと、通常どおり拾い出し結果が出ます

入力した内容はブラウザに**ためられ、次に読む図面でもそのまま使われます**。
別の図面を読み込んで未登録の字形が出てきたら、拾い出し欄の
「線で描かれた文字を教える・追加する」から**そのぶんだけ足していけます**
（覚えている字形は入力済みで出るので、毎回ぜんぶ入力し直す必要はありません）。

縦書き（90度回転）の字形には、横書きで入力した文字からの候補をグレーで入れますが、
**自動では確定しません**。9 が 6 の180度回転になっているフォントでは回転させた形が
一致してしまい、6000 を 9000 と読む事故が起きるためです。必ず目で確認してください。

なお、**スキャン（画像）PDF は読み取れません。** 画素から文字を起こすには OCR が
必要で、このツールは外部ライブラリを使わない方針のため入れていません。
その場合は「AIで総ざらい」をお使いください。

### 読み取りのルール

- 通り芯は **円（バブル）で囲まれた X○○ / Y○○** だけを拾います。縦方向（X方向）は
  X○○、横方向（Y方向）は Y○○。X2.5・Y4.7 のような小数点付きも拾います。
  円で囲まれていない文字や、符号のない鎖線は拾いません。
- **上辺・右辺・下辺・左辺の4辺それぞれ**について、その辺に符号がある通り芯と、
  その辺の寸法線から読んだ芯々寸法を拾い出します。X2.2 のように**一部の範囲に
  しか引かれていない通り芯**も、円囲みの符号があれば拾います。
- 1枚の用紙に**複数の図（右下のキープランなど）**が載っている場合は、
  **一番大きく描かれている図だけ**を拾います（符号の大きさで図を見分けます）。
- 寸法は作図距離の測定値ではなく、**図面に記載された数字**です。
  「黒いドット間にある直線の上の数字」を読み、通り芯間で分割記載されている場合は
  合計し、内訳を括弧で併記します（小数点も可）。
  拾うのは**数字だけ**ですが、開口幅の「**W＝1650**」のように W＝ が付いたものも
  数字（1650）として拾います。
- **通り芯以外の寸法線**（室内寸法・開口幅など）も寸法線（段）ごとに拾い出します。
  通り芯の分割寸法には使いません（開口幅が内訳に混ざらないように）。
- **縮尺は使いません。** 結果はすべて図面に書かれた寸法値です。

### 拾い出し結果の表記

X方向（上辺・下辺）と Y方向（右辺・左辺）に分け、各方向の2辺を横並びで表示します。

```
■X方向
上辺                          下辺
X1~X2  ：5917（2730.5+3186.5） X1~X2  ：5917
X2~X3  ：3175                 X2~X3  ：3175
X3~X4  ：4200（1600+2600）     X3~X4  ：4200

■Y方向
右辺                          左辺
Y1~Y2  ：6000                 Y1~Y2  ：6000
```

### AIで総ざらい（任意・要サーバ設定）

自動読み取りの取りこぼしを確かめたいときに使います。押すとその図面PDFが
Anthropic の API に送られ、AI が通り芯と寸法を読み取って、自動読み取りの結果と
突き合わせた差分（相違 / 自動のみ / AIのみ）が表示されます。

- **押さない限り外部送信はありません。**
- 使うには API キーをサーバ側に設定する必要があります（下記「デプロイ」参照）。
  未設定の場合はボタンを押すとエラーメッセージが出るだけで、他の機能に影響はありません。
- AI の読み取りも誤りうるため、相違が出た箇所は必ず図面で確認してください。

### 表示の切り替え

拾い出し結果の右上のチェックで、表示するものを選べます（**複数選択可**）。

- **通り芯** … 円囲み符号（X○○/Y○○）と、その芯々寸法
- **その他の寸法** … 通り芯間として拾えなかった寸法線（室内寸法・開口幅 W＝ など）を
  寸法線ごとに一覧します

同じチェックが図面上の寸法表示にも効きます（「寸法表示」がONのとき）。
照合するのは通り芯の寸法だけです（その他の寸法は符号が無く2図面間で対応付け
できないため、拾い出しと表示のみ）。

### ビュワーの操作

- **ホイール**: 拡大縮小 / **ドラッグ**: 移動 / **ダブルクリック・フィット**: 全体表示
- **芯にカーソル**: 符号と辺をツールチップ表示 / **芯をクリック**: 拾い出し対象のON/OFF
- **寸法表示**: 辺ごとの記載寸法を図上にオーバーレイ
- **測定**: 2点間の図上距離(pt)を計測（芯・線分端点にスナップ、Escで解除）
- 照合結果の行にカーソルを乗せると、該当箇所が両方のビュワーで強調されます
- ビュワーは下端をドラッグすると高さを変えられます
- 図面に文字として入っている寸法・室名・記号は、**元の PDF と同じ位置に表示**
  されます（拡大すると読めます）。ツールが拾った数字と図面の記載を見比べて
  確認できます

### 通り芯の符号について

- 拾うのは**円（または長円）で囲まれた** `X○○` / `Y○○` の符号だけです
- `X2.2` `Y4.1` のような**小数点付きの通り芯**も拾います。符号が長くて
  横長の長円で囲まれていても、CAD の都合で符号が分かれて出力されていても
  同じように読みます
- 線で描かれた文字の図面（CADのSHXフォント）では、**小数点の字形も
  「線で描かれた文字を教える」で教えてください**。教えていない字が 1 つでも
  あるとその行はまるごと捨てるため、`X2.2` の通り芯が出てきません
- **円で囲まれていない符号も拾います**。構造図は細分の通り芯（`X2.2` `Y8.2` など）を
  円で囲まずに線の脇へ書くことがあるためです。ただし部材符号（`Y1.1` など）と
  区別するため、**既にある符号の番号のあいだに収まり、線のすぐ脇にあるもの**
  だけを拾います。拾ったものは読み込み結果に「円で囲まれていない符号」として出ます

## 分割された図面（1つの建物を上下/左右に分けて描いたもの）

平面詳細図のように、**1つの建物を上下（または左右）に分けて複数ページに描いた図面**は、
1ページだけで照合すると「そのページに載っていない範囲」がすべて差異になってしまいます。

PDFを読み込むと（4ページまでは自動で）全ページを調べ、分割された図面なら

> この図面は1つの建物を上下に2分割して描いています
> 1ページ目 … Y1 〜 Y5（7本）　2ページ目 … Y4 〜 Y9（8本）
> ページの重なり: Y4 Y4.1 Y4.7 Y5

のように表示し、**全ページをまとめて1つの図面として照合**します（チェックで切り替え可）。
ページどうしが重なっている範囲で記載寸法が食い違っていれば、それも知らせます。

### 照合の単位

- **辺ごと**（既定）… 上辺・右辺・下辺・左辺を別々に照合します。同じ種類の図面どうし向け
- **方向ごと（X/Y）** … 上辺と下辺、右辺と左辺をまとめて照合します。
  **平面図と構造図のように、符号を書く辺が違う図面どうしはこちら**を選んでください
  （辺ごとだと「構造図は符号を下辺にしか書かない」というだけで差異が大量に出ます）

区間の切りかたが違っても（平面図は `X2~X2.2` + `X2.2~X3`、構造図は `X2~X3`）、
記載値の合計で突き合わせます。

### 照合結果の色分け

照合すると、結果が両方のビュワーに色で表示されます
（「照合結果を図面に色で表示」で切り替え）。

- **黄色** … 一致（左右の図面で同じ通り芯・同じ記載寸法）
- **赤** … 差異（記載寸法が違う / 片方にしか無い通り芯）
- **橙** … 要確認（片方で寸法が読めなかった区間）

色が付くのは**通り芯の符号と寸法の数字だけ**です。寸法線や通り芯の線には
色を付けないので、図面はそのまま読めます。

左右の図面を見比べると、**合っているところは黄色、食い違っているところは赤**で
すぐ分かります。色の意味は照合結果の表の上にも凡例として出ます。

## 開発

```bash
npm test          # 回帰テスト
npm run build     # dist/zumen-check.html を再生成

# 辺別の拾い出し結果をCLIで確認（UIと同じロジック）
npm run inspect -- 図面.pdf
npm run inspect -- 基準.pdf 比較.pdf   # 2枚を照合（--json / --axes / --others / --page 等あり）
```

ビルドは `src/js/_order.json` の順にファイルを連結するだけです。
バンドラも実行時の依存もありません。

詳しい仕様と注意点は [CLAUDE.md](./CLAUDE.md) を参照。

## デプロイ（AI機能を使う場合）

AI機能は Vercel のサーバ関数 `api/analyze.js`（リポジトリのルート）が担当します。
API キーはこの関数の環境変数にだけ置き、ブラウザには渡しません。

1. Vercel のプロジェクト設定 → Environment Variables に `ANTHROPIC_API_KEY` を追加
2. 再デプロイ

AI機能を使わない場合は設定不要で、`dist/zumen-check.html` を開くだけで従来どおり動きます。

## 制限

- ベクター PDF のみ。スキャン（ラスタ）PDF は読み取れません。
- **文字を線に変換して出力された PDF は読み取れません。** CAD のシングルストローク
  （SHX）フォントのまま PDF 化すると、数字も通り芯の符号も「線の集まり」になり、
  PDF に文字データが残りません。この場合は読み込み時に警告を出します。
  CAD から TrueType フォント（MSゴシック等）で書き出し直すか、
  「AIで総ざらい」（AIは図として読みます）をお使いください。
- 読み取れない図面は「読み取り条件の診断」で原因を表示します（上記「読み取れる
  図面の条件」参照）。
- 検出されなかった箇所に差異が無いことを保証するものではありません。
  最終確認は必ず図面で行ってください。
