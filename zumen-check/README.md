# 通り芯照合ツール

基準図面と比較図面（他社作成図など）の PDF を読み込み、通り芯と芯々寸法の
食い違いを洗い出します。ブラウザだけで動作し、図面は外部に送信されません。

## 使う

`dist/zumen-check.html` をブラウザで開く。

1. 基準図面の PDF を読み込んで通り芯を判定
2. 比較図面で同じ操作
3. チェック項目を選んで照合

誤検出した通り芯はチェックを外して除外できます。

### 読み取りのルール

- 通り芯の符号は、縦方向（X方向）= **X○○**、横方向（Y方向）= **Y○○** と
  記載されているものだけを拾います（X2.5 のような小数点付きも可）。
- 芯々寸法は作図距離の測定値ではなく、**図面に記載された寸法の数字**を読み取って
  照合します。寸法は「黒いドット間にある直線の上の数字」を対象とし、
  通り芯間で分割記載されている場合は分割値の合計を使います（小数点も可）。
- 記載寸法が見つからない区間だけ、作図距離×縮尺で補います（結果に注記されます）。

### ビュワーの操作

- **ホイール**: 拡大縮小 / **ドラッグ**: 移動 / **ダブルクリック・フィット**: 全体表示
- **芯にカーソル**: 測定値をツールチップ表示 / **芯をクリック**: 照合対象のON/OFF
- **寸法表示**: チェック中の芯の芯々寸法を図上にオーバーレイ
- **測定**: 2点間の実寸距離を計測（芯・線分端点にスナップ、Escで解除）
- 照合結果の行にカーソルを乗せると、該当箇所が両方のビュワーで強調されます
- ビュワーは下端をドラッグすると高さを変えられます

## 開発

```bash
npm test          # 回帰テスト
npm run build     # dist/zumen-check.html を再生成

# 取り込み・測定結果をCLIで確認（UIと同じロジック）
npm run inspect -- 図面.pdf
npm run inspect -- 基準.pdf 比較.pdf   # 2枚を照合（--json / --texts / --scale 等あり）
```

ビルドは `src/js/_order.json` の順にファイルを連結するだけです。
バンドラも実行時の依存もありません。

詳しい仕様と注意点は [CLAUDE.md](./CLAUDE.md) を参照。

## 制限

- ベクター PDF のみ。スキャン（ラスタ）PDF は読み取れません。
- 検出されなかった箇所に差異が無いことを保証するものではありません。
  最終確認は必ず図面で行ってください。
